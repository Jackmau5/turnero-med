# Turnero Med

El código de la aplicación está en dos carpetas:

- [front-turnero-med](front-turnero-med/) contiene la interfaz web hecha con React.
- [backend-turnero-med-main](backend-turnero-med-main/) contiene la API hecha con Spring Boot y la configuración de la base de datos.

Para ejecutar Turnero Med, iniciá ambos proyectos siguiendo las instrucciones del [README del backend](backend-turnero-med-main/README.md) y del [README del frontend](front-turnero-med/README.md).

El [mockup](Turnero%20Med%20-%20Mockup.html) es una referencia visual del diseño.
